Command-line administration

Web Fleet supports headless first-run provisioning and machine-readable configuration inspection.

webfleet setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password
webfleet config show --json
webfleet service status
webfleet reset --auth --confirm "WEBFLEET AUTH"
webfleet reset --all --confirm "WEBFLEET ALL"

Stop Web Fleet before reset. Timestamped backups are retained. Reset currently operates on SQLite and fails closed for PostgreSQL, where you should use a database-native backup and reset workflow.

Environment variables, service commands, backup/restore operations and the HTTP API provide stable primitives for SSH orchestration and generated deployment scripts. Passwords belong in files, not process arguments.

Replication operators

When clustering is enabled, use the authenticated operator surface to inspect Raft state, add voters explicitly and request a snapshot.

webfleet replicate status --user admin@example.com --password '...'
webfleet replicate join --user admin@example.com --password '...' wf-node-b 10.0.0.11:7440
webfleet replicate snapshot --user admin@example.com --password '...'

Gantry pairing and Raft voter membership are separate. See Clustering.
