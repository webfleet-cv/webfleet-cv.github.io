Command-line administration

webfleet setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password
webfleet config show --json
webfleet reset --auth --confirm "WEBFLEET AUTH"
webfleet reset --all --confirm "WEBFLEET ALL"

Stop Web Fleet before reset. SQLite backups are retained; PostgreSQL reset fails closed.
