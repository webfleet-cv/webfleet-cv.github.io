Convenient browser access

my.webfleet.cv is a memorable shortcut to your Web Fleet dashboard. It means you do not need to remember port 7336 or manually type a localhost address and port.

Configure it once

  1. Open my.webfleet.cv?config.
  2. Keep the defaults for a local Web Fleet instance, or enter a remote domain or IP address and port.
  3. Select Save, then Open.

Future visits to my.webfleet.cv forward directly to the saved destination.

Browser-local setting: the destination is stored in the current browser profile. Configure it separately on another browser, profile, or device, and revisit the ?config URL when the host or port changes.

Local default

http://localhost:7336

Remote instances

The shortcut accepts a domain or IP address as well as a port, but it only performs browser navigation. It is not a proxy and does not expose Web Fleet to the network. Follow Hosting and deployment and the HTTPS guides for remote access.
