Deployment

Caddy

Caddy is a straightforward way to give Web Fleet a company subdomain with automatic HTTPS.

1. Point DNS at the server

webfleet.company.com → your server IP

2. Proxy Web Fleet

webfleet.company.com {
    reverse_proxy 127.0.0.1:7336
}

Keep Web Fleet itself on loopback when Caddy is the public entry point. Caddy obtains and renews the public TLS certificate.

3. Validate and reload

sudo caddy validate --config /etc/caddy/Caddyfile
sudo systemctl reload caddy
curl -I https://webfleet.company.com/healthz
